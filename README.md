# juppaluri.github.io

Personal academic website for Jayanth Uppaluri, built with [Quarto](https://quarto.org/) from the [Quarto Academic Website Template](https://github.com/drganghe/quarto-academic-website-template) by Dr. Gang He.

Edit the `.qmd` files and `_quarto.yml`, run `quarto render`, and GitHub Pages serves the output in `docs/`.
